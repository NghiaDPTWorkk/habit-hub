Design Strategy

Fulfilling requirements with a streamlined, mobile-first design.

Ideation & Pain Points

Team Alignment

Our team sat down to analyze existing habit trackers. We identified major drawbacks: complex user interfaces, high friction, and cluttered screens that overwhelm daily logging.

Clutter-Free Features

Streamlined

We designed a streamlined layout that satisfies all prompt requirements (CRUD habits, goals, check-ins, dashboard stats) while eliminating modern interface clutter.

Touch-First Mobile UX

Mobile Testing

We prioritized mobile testing and one-tap touch check-ins. We also integrated clear visual indicators and navigation guides so new users never feel lost.

UI Design Standards

  • — Color codes must not be hardcoded in standard styles or JSX.
  • — Do not use raw pixels (px) for spacing or typography.
  • — Avoid direct MUI component imports outside the UI feature layer.

Deployment Flow

Automated continuous integration and deployment pipeline powered by AWS services.

1

Local Commits

Husky enforces pre-commit hooks (Prettier format checks, ESLint analysis, test validation) locally.

2

Pull Request Staging

Pull Requests targeting the develop branch trigger AWS services to build and deploy to Staging environments.

3

Production Deploy

Merging develop into main triggers production compilation and serves the app over CloudFront CDN.

Lessons & Limitations

Key engineering insights gained from the sprint and current technical limitations.

Key Takeaways & Lessons Learned
  • Strict Boilerplate Standardization: Enforcing UI wrapper architectures and linting checks keeps code uniform, preventing early-stage technical debt.
  • Modular State Slicing: Segmenting the Zustand store allows developers to work on features independently without state overlap issues.
  • Continuous Integration Checkpoints: Continuous staging builds enable QA engineers to identify edge-case bugs (e.g. check-in timeline margins) very early.
Technical Limitations
  • Local Client-Side Storage: App data is stored in LocalStorage, rendering it prone to loss during browser cache clear cycles.
  • Missing User Authentication: The current build lacks credential verification, role-based access controls, and API security layers.
  • No Server Database Integration: Static mock hosting makes retention analytic calculations completely client-dependent.
